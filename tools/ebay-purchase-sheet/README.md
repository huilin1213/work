# eBay 采购记录自动同步

每天早上 9 点和晚上 8 点（英国时间），从 Gmail 里的 eBay **"Order confirmed"** 邮件自动提取采购记录，
写进 Google 表格 **eBay 采购记录（自动同步）** 的 `eBay采购记录` 标签页。不用再手动复制订单号。

- 运行在 Google Apps Script 上（Google 自己的服务器），电脑关机也照常运行，不需要 eBay API 密钥。
- 每件商品一行：下单时间、订单号、Item ID、标题、品牌/单条容量/频率/料号（从标题自动识别）、
  每件条数(估)、购买数量、卖家、单价、买家保护费、运费、实付总额、预计送达、eBay 订单链接、原始邮件链接。
- 收到 eBay 的取消 / 退款邮件后，对应行的「状态」会自动从「已下单」改成「已取消」/「已退款」。
  手动改过的状态（例如「已收到/已检查」）不会被覆盖。
- 同一个订单不会重复写入；每天扫描最近 7 天的邮件，漏跑一两天也能自动补上。
- 「备注(手填)」等列可以随便手动填写，自动同步不会动它们。

## 安装（只需一次，约 3 分钟）

1. 打开表格：https://docs.google.com/spreadsheets/d/141O1j1zURNc6ngdEhwzkwGO-yk17qKeiE2dSC9g7s3Q/edit
2. 菜单 **扩展程序 → Apps Script**。
3. 把编辑器里默认的代码全部删掉，粘贴 [`Code.gs`](Code.gs) 的全部内容，按 Ctrl/Cmd+S 保存。
4. 顶部函数下拉框选 **`setup`**，点 **运行**。
5. 弹出授权窗口 → 选 contact@bluebridgewell.com → "高级" → "转至…（不安全）" → 允许
   （这是你自己的脚本，需要读取 Gmail 和编辑表格的权限）。
6. 运行完成后回到表格，会看到从 2026/07/01 起的所有 eBay 订单。以后每天 9 点和晚上 8 点自动更新。

可在 Apps Script 左侧 **触发器（闹钟图标）** 里看到 `dailySync` 每日触发器；**执行记录** 里能看到每次跑的结果。
想立刻手动更新一次：函数下拉框选 `dailySync` → 运行。

## 说明 / 限制

- Google 的定时触发器会在设定时间前后约 15 分钟内执行，不是精确到秒。
- 修改同步时间：改 `Code.gs` 顶部 `CONFIG.TRIGGER_HOURS`（如 `[9, 20]`），保存后运行一次 `updateSchedule`。
- 「品牌/容量/频率/料号/每件条数」是根据商品标题猜的，标题写得不规范时可能为空，需要手动补。
- 「运费」和「实付总额」是整单金额；如果一次结账买了多件，这两列在每一行上都会重复显示整单数字。
- 只读取发件人为 `ebay@ebay.com` / `ebay@ebay.co.uk` 的邮件；如果你把这些邮件删了，就同步不到。
- 修改配置（回填起始日期、时区、触发时间）：改 `Code.gs` 顶部的 `CONFIG`，保存后重新运行一次 `setup`。

## 开发

`node test.js` 用脱敏后的邮件样例离线测试解析函数。

# 直采发票同步（Direct.gs）

直接向供应商（Steve、Chaps IT 等）采购的发票，自动整理进同一个表格，**按供应商分组**。
和 eBay 同步共用同一个定时任务（每天 9:00 和 20:00）。

## 日常只需要做的事

| 发票从哪来 | 你要做什么 |
|---|---|
| 供应商**发邮件**（PDF 附件） | **什么都不用做**：只要供应商在「直采供应商」表里，附件会自动存进 Drive 并录入表格 |
| 供应商发 **WhatsApp** / 纸质拍照 | 存进 Drive「直采发票/供应商名」文件夹 |
| 来了**新供应商** | 在「直采供应商」标签页加一行：名字 + 邮箱 |

想马上看到结果，不等定时：表格菜单 **采购工具 → 只同步直采发票**。

## 三个标签页

- **直采供应商**：供应商名单（名字、邮箱，多个邮箱用逗号隔开）。名字就是 Drive 里的文件夹名，大小写不敏感。
  没有邮箱的供应商只填名字即可。
- **直采记录**：每张发票上的每个商品一行，**按供应商分组**，组内最新发票在前，**每张发票一种底色**。
  列：发票日期、供应商、发票号、行号、商品描述、品牌、单条容量、频率、料号、数量、单价、金额、
  发票总额(含VAT)、不含VAT（这两列只在每张发票第一行）、核对、备注(手填)、发票文件链接。
- **直采汇总**：每个供应商一行：发票数、商品数量、不含VAT合计、含VAT合计、最近一张发票日期、需核对的发票数，
  最后一行是全部合计。每次同步自动重算。

「核对」列：程序把一张发票所有商品的金额相加，和发票上的 SUB-TOTAL 对比。**✓** 表示全部识别正确；
**⚠** 表示有漏行或识别错，点「发票文件」打开原件核对。

## 自动规则（不用操心，但需要知道）

- 只收供应商发来的 **PDF 附件**；你自己的回复、邮件正文、照片都不读。
- 邮件里的 PDF 如果通篇没有 "invoice" 字样（报价单、价目表），会被自动丢进回收站，不进表格，以后也不会再导入。
- 同一份 PDF 已经在 Drive 里（以前手动存过，或供应商重复发送），不会重复导入。
- 每个文件只识别一次。想重新识别某张发票：在「直采记录」里删掉它的所有行，再同步一次。
  识别规则更新后想全部重新识别：菜单 **采购工具 → 重新识别全部直采发票**（旧表改名保留，不会丢备注）。
- 一次运行最多处理约 4.5 分钟，发票特别多时剩下的会在下一次同步继续。
- 以后程序如果改了表格的列，旧的「直采记录」会自动改名为「直采记录(旧版 …)」保留，新表自动从 Drive 重建，不用手动删。

## 识别方式

Google Drive 自带的免费 OCR 把 PDF/图片转成文字，再按规则提取发票号、日期、每一行的「描述 数量 单价 金额」，
以及从描述里识别的品牌/容量/频率/料号。按 Steve、Chaps IT、SecureIT 的发票格式验证过（Chaps IT 的 4 位小数单价、VAT 税率列、换行断开的料号都能处理）；其他格式如果识别不好，告诉我调整规则。

## 安装 / 升级

1. Apps Script 编辑器里 `Direct.gs` 的内容换成最新版，保存。
2. 函数下拉框选 **`setupDirect`** → Run（首次会请求 Drive/Docs 权限）。
3. 刷新表格，顶部菜单栏会出现 **采购工具**。以后同步、重新上色都用这个菜单，不用再打开 Apps Script。
