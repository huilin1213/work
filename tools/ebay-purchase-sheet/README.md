# eBay 采购记录自动同步

每天早上 9 点和晚上 8 点（英国时间），从 Gmail 里的 eBay **"Order confirmed"** 邮件自动提取采购记录，
写进 Google 表格 **eBay 采购记录（自动同步）** 的 `eBay采购记录` 标签页。不用再手动复制订单号。

- 运行在 Google Apps Script 上（Google 自己的服务器），电脑关机也照常运行，不需要 eBay API 密钥。
- 每件商品一行：下单时间、订单号、Item ID、标题、品牌/单条容量/频率/料号（从标题自动识别）、
  每件条数(估)、购买数量、卖家、单价、买家保护费、运费、实付总额、预计送达、eBay 订单链接、原始邮件链接。
- 收到 eBay 的取消 / 退款邮件后，对应行的「状态」会自动从「已下单」改成「已取消」/「已退款」。
  手动改过的状态（例如「已收到/已检查」）不会被覆盖。
- 同一个订单不会重复写入；每天扫描最近 7 天的邮件，漏跑一两天也能自动补上。
- 「备注(手填)」等列可以随便手动填写，自动同步不会动它们。

## 安装（只需一次，约 3 分钟）

1. 打开表格：https://docs.google.com/spreadsheets/d/141O1j1zURNc6ngdEhwzkwGO-yk17qKeiE2dSC9g7s3Q/edit
2. 菜单 **扩展程序 → Apps Script**。
3. 把编辑器里默认的代码全部删掉，粘贴 [`Code.gs`](Code.gs) 的全部内容，按 Ctrl/Cmd+S 保存。
4. 顶部函数下拉框选 **`setup`**，点 **运行**。
5. 弹出授权窗口 → 选 contact@bluebridgewell.com → "高级" → "转至…（不安全）" → 允许
   （这是你自己的脚本，需要读取 Gmail 和编辑表格的权限）。
6. 运行完成后回到表格，会看到从 2026/07/01 起的所有 eBay 订单。以后每天 9 点和晚上 8 点自动更新。

可在 Apps Script 左侧 **触发器（闹钟图标）** 里看到 `dailySync` 每日触发器；**执行记录** 里能看到每次跑的结果。
想立刻手动更新一次：函数下拉框选 `dailySync` → 运行。

## 说明 / 限制

- Google 的定时触发器会在设定时间前后约 15 分钟内执行，不是精确到秒。
- 修改同步时间：改 `Code.gs` 顶部 `CONFIG.TRIGGER_HOURS`（如 `[9, 20]`），保存后运行一次 `updateSchedule`。
- 「品牌/容量/频率/料号/每件条数」是根据商品标题猜的，标题写得不规范时可能为空，需要手动补。
- 「运费」和「实付总额」是整单金额；如果一次结账买了多件，这两列在每一行上都会重复显示整单数字。
- 只读取发件人为 `ebay@ebay.com` / `ebay@ebay.co.uk` 的邮件；如果你把这些邮件删了，就同步不到。
- 修改配置（回填起始日期、时区、触发时间）：改 `Code.gs` 顶部的 `CONFIG`，保存后重新运行一次 `setup`。

## 开发

`node test.js` 用脱敏后的邮件样例离线测试解析函数。

# 直采发票同步（Direct.gs）

直接向商家（Steve 等）采购的发票，自动识别后写进同一个表格的 **「直采记录」** 标签页，
和 eBay 同步共用同一个定时任务（每天 9:00 和 20:00）。

## 用法：只有一个文件夹

把所有直采发票（PDF 或照片）放进 Google Drive 的 **「直采发票」** 文件夹，就会被自动识别，每个文件一行。
程序**不读邮件**，只认这个文件夹。

- 邮件里的发票：打开附件右上角的 **Add to Drive（添加到云端硬盘）** → 选「直采发票」文件夹。
- WhatsApp 里的发票：长按文件/图片 → 分享 → Drive → 选「直采发票」文件夹。
- **可以按供应商建子文件夹**，比如 `直采发票/Steve`、`直采发票/Tech Store`：子文件夹里的发票，
  「供应商」一列直接填子文件夹名字（比 OCR 识别更准）。子文件夹里还可以再分子文件夹（如按月份），
  供应商仍按最外层的子文件夹名算。
- 直接放在「直采发票」根目录的发票：供应商靠识别，识别不出就用文件名。
- 文件在子文件夹之间移动不会产生重复的行。

每个文件只处理一次。想重新识别某张发票：在表格里删掉那一行，再运行一次同步。

**一次性导入某个供应商邮件里的全部 PDF**：在 `Direct.gs` 的 `EMAIL_IMPORTS` 里写上供应商邮箱和文件夹名
（已有 Chaps IT），运行 `importEmailInvoices`。附件会存进「直采发票/文件夹名」，文件名前加上邮件日期，
然后自动同步进表格。可以重复运行，已存过的附件会跳过。

## 表格格式：一个商品一行

每张发票上的每一行商品，在表格里单独占一行：

| 发票日期 | 供应商 | 发票号 | 行号 | 商品描述 | 品牌 | 单条容量 | 频率 | 料号 | 数量 | 单价 | 金额 | 核对 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 2026-09-22 | Steve | 220926-1 | 2 | 32gb PC4-2666 ECC Reg Hynix HMA84GR7AFR4N-VK | SK Hynix | 32GB | 2666 | HMA84GR7AFR4N-VK | 4 | £54.00 | £216.00 | ✓ 明细合计=发票小计 |

- 可以按料号、品牌、容量筛选（Data → Create a filter），一眼看出每个型号买了多少、什么价。
- 「核对」列：程序把所有商品的金额加起来，和发票上的 SUB-TOTAL 对比。
  **✓** 表示一张不漏全识别出来了；**⚠** 表示有漏行或识别错，请点「发票文件」打开原件核对。
- **同一张发票的所有行是同一种底色**，相邻两张发票颜色不同，一眼分清哪几行属于哪张发票。
  手动删过行后颜色乱了：运行一次 `recolorDirect` 重新上色。
- 「发票总额(含VAT)」「不含VAT」只写在每张发票的**第一行**，这样对整列求和时不会重复计算。
- 价格是发票上的不含 VAT 单价。
- 识别不出商品明细的发票（比如照片太模糊），会留一行「未识别到明细」，提醒你手动处理。

## 识别方式

用 Google Drive 自带的免费 OCR 把 PDF/图片转成文字，再按规则提取：发票号、发票日期、
每一行的「描述 数量 单价 金额」，以及从描述里识别的品牌/容量/频率/料号。
按 Steve 发票的格式（DESCRIPTION / QTY / PRICE / AMOUNT 表格）做过测试；其他供应商格式不同时可能需要调整规则。
支持 PDF / JPG / PNG；照片拍得越正越清楚，识别越准。

## 安装（在已装好 eBay 同步的同一个 Apps Script 里）

1. Apps Script 编辑器左侧 **Files** 旁边点 **+ → Script**，命名为 `Direct`，粘贴 `Direct.gs` 全部内容，保存。
2. 用新版 `Code.gs` 替换原来的 `Code.gs` 内容并保存（加了定时同步时顺带同步直采发票）。
3. 函数下拉框选 **`setupDirect`** → Run，按提示授权（Drive 和 Docs 权限）。
4. 完成后 Drive 里会出现「直采发票」文件夹，表格里会出现「直采记录」标签页。

不想等到下一次定时同步：函数下拉框选 `syncDirectNow` → Run，立即同步一次。
